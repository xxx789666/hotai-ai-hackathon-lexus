# T4：本機 LLM2Jev 600 句試標（對 Sonnet）

日期：2026-09-24。全程本機 prefill，沒有呼叫雲端 LLM。

## 環境與模型

- Windows 11，RTX 4060 Ti 8 GB，Python 3.12，torch 2.6.0+cu124，`torch.cuda.is_available()` 為 True。
- 模型：`Qwen/Qwen3-4B-Instruct-2507`，bitsandbytes NF4 4-bit（雙重量化，compute dtype bf16）。
- 權重快取：`D:\hf_cache`（`HF_HOME`）。VRAM 峰值 **3.76 GB**（`torch.cuda.max_memory_allocated()`）。
- 600 句全部跑完。每句平均 **4.34 秒**（含該句全部題目）。主跑 599 句牆鐘 2599.5 秒；第一句試跑 3.77 秒已寫進同一份 jsonl。

## 安裝過程

走的是 LLM2Jev，不是自寫備援評分。

1. `git clone https://github.com/Yinsongxu/LLM2Jev` 到 `vendor/LLM2Jev`（已加入 `.gitignore`）。
2. worktree `.venv`（`--system-site-packages`，沿用已裝的 torch）執行 `pip install -e "vendor/LLM2Jev[transformers]" bitsandbytes`。bitsandbytes 0.50.2 在 Windows 可載入。
3. 上游 `TransformersBackend` 只會以 bf16 載入再 `model.to(cuda)`，4B 放不進 8 GB。因此在 `local_jev/quant_backend.py` 子類化，改為 NF4 載入，評分仍呼叫 `LLM2Jev.evaluate()`（yes/no 單 token prefill，Choice／Score 由套件拆成候選題再 L1 正規化）。沒有改 `vendor/` 裡的檔案。

## 題目設計

同一句的 State 格式對齊 `pipeline/verify_churn.py` 的 `call_llm`：標題（40 字）、前 2 句（各 120 字）、`>>>` 目標句、後 1 句。criteria 沿用 `verify_churn.py` 的 c／w 定義，以及 `label_aspects.py` 的面向、情緒、替代選項、車型文字。

| 題目 | 型別 | 選項 |
| --- | --- | --- |
| churn | Score 4 級 | c = 0／1／2／3 的原定義 |
| stance | Choice | s 自身／a 建議他人／o 轉述 |
| asp_價格 … asp_銷售交車 | Noul × 9 | 各面向定義 |
| sentiment | Score 3 級 | 負面／中性／正面 |
| mentions_lexus | Noul | 有沒有談到 Lexus 原廠；低於 0.5 則不填 s |
| alt_* | Noul × 6 | 替代選項定義與排除條件 |
| model | Choice | 15 車型 + 無 |

輸出：`data/processed/jev_pilot_local.jsonl`（600 個不重複 sid，與 `aspect_pilot_sonnet.jsonl` 相同）。`c` 同時存 `c_expect`（Score 期望值四捨五入）與 `c_argmax`。面向與替代選項以 Noul ≥ 0.5 寫入 `a`／`alt`。

## 能不能當 L3 輕量分類器

**現在不能。** 零樣本 4-bit Qwen3-4B 的 prefill 機率沒有達到「c≥2 二元 ≥ 90%」這條線。c_expect 二元一致率 83.5% 還低於全猜負例的 89.2%，κ 只有 0.21，二元 F1 0.30。面向 micro F1 0.46，低於 Haiku 的 0.60。機率有單調性，但沒有校準，高分桶仍然大多不是流失。

它適合當「本機 System-One 介面已經跑得動」的證據：8 GB 顯卡、4-bit、每句約 4 秒、峰值 3.8 GB。不適合直接拿來做 L3 監測或 L4 風險排序。

## 若要微調

1. 用已複核的 21,183 句當監督，優先把流失二元（以及四級）微調進同一套 yes/no 候選題，而不是先換更大的模型。正例要過採樣，否則還是會塌成「幾乎全是 0」。
2. 微調後重畫這張五段 reliability table；c≥2 的 F1 與 κ 要比這次的 0.30／0.21 明顯上升，才值得取代 BERT 計畫。
3. 面向可以後做。零樣本已經有中等召回，門檻 0.7 只把 micro F1 拉到 0.48，還是不如 Haiku，代表差在語意而不只是門檻。
4. 情緒與車型目前偏差大（情緒幾乎只出中性；ES／RX 過度觸發）。這兩題不要跟流失綁成同一個上線模型，除非分開微調後再測。
